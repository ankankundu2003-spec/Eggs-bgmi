# BGMI Lucky Egg Finder

A standalone Android companion-app starter with map selection for Erangel, Miramar, Sanhok, Vikendi, Livik, Nusa and Karakin.

## Build APK
1. Create a GitHub repository and upload these project files.
2. Open the **Actions** tab and run **Build Lucky Egg Finder APK** (or push to `main`).
3. Download the `Lucky-Egg-Finder-APK` artifact from the completed workflow run. The APK inside is `app-debug.apk`.

This starter intentionally does not access or modify BGMI, inspect game memory, automate gameplay, or bypass anti-cheat. It currently has no verified event coordinates; add current official event locations before relying on it.
